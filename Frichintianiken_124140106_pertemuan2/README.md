# Aplikasi Jadwal Kuliah

## Deskripsi
Aplikasi Jadwal Kuliah dibuat untuk membantu mencatat dan mengatur jadwal kuliah. Aplikasi ini bisa digunakan untuk menambah, mengedit, menghapus, dan melihat jadwal berdasarkan hari.

## Fitur
- Menambah, mengedit, dan menghapus jadwal kuliah.
- Melihat jadwal berdasarkan hari.
- Menampilkan jam dan sapaan sesuai waktu.
- Menampilkan informasi cuaca.
- Mengubah tema terang dan gelap.
- Menyalin jadwal dan membagikannya ke WhatsApp.
- Menyimpan jadwal agar tidak hilang saat halaman dimuat ulang.

## Teknologi
- HTML
- Tailwind CSS
- JavaScript
- Local Storage
- Fetch API

## Penerapan JavaScript ES6+
Beberapa fitur ES6+ yang digunakan dalam aplikasi ini:
- `const` dan arrow function.
- Class dan static method.
- Template literals.
- Ternary operator.
- Destructuring dan spread syntax.
- Nullish coalescing (`??`).
- Array methods seperti `map()`, `filter()`, dan `sort()`.
- `async/await`.
